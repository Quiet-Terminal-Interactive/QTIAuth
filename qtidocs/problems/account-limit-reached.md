# ACCOUNT_LIMIT_REACHED

## Code

- `https://qtiauth.qtidocs.dev/problems/account-limit-reached`

- `409`

## Meaning

The email address has reached the maximum number of accounts.

## What to do

Inform the user they cannot create another account with this email.
