# WEBHOOK_URL_NOT_ALLOWED

## Code

- `https://qtiauth.qtidocs.dev/problems/webhook-url-not-allowed`
- `WEBHOOK_URL_NOT_ALLOWED`
- `422`

## Meaning

The webhook URL resolves to a private or internal IP address.

## What to do

Use a publicly accessible HTTPS URL for the webhook endpoint.
