# PASSKEY_NOT_RECOGNISED

## Code

- `https://qtiauth.qtidocs.dev/problems/passkey-not-recognised`
- `PASSKEY_NOT_RECOGNISED`
- `401`

## Meaning

The passkey presented is not registered for this user.

## What to do

Ask the user to use a passkey they have previously registered, or register a new one.
