# PROVIDER_TOKEN_EXCHANGE_FAILED

## Code

- `https://qtiauth.qtidocs.dev/problems/provider-token-exchange-failed`
- `PROVIDER_TOKEN_EXCHANGE_FAILED`
- `502`

## Meaning

The OAuth provider token exchange (authorization code to access token) failed.

## What to do

Check the provider's availability and the client credentials. Retry after a delay.
