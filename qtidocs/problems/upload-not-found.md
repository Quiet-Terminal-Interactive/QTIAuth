# UPLOAD_NOT_FOUND

## Code

- `https://qtiauth.qtidocs.dev/problems/upload-not-found`
- `UPLOAD_NOT_FOUND`
- `404`, `409`

## Meaning

The upload record was not found, or the record exists but the file data has not been transferred yet.

## What to do

For 404: verify the upload ID. For 409: wait for the file transfer to complete before proceeding.
