# NOT_A_PROGRESS_ACHIEVEMENT

## Code

- `https://qtiauth.qtidocs.dev/problems/not-a-progress-achievement`
- `NOT_A_PROGRESS_ACHIEVEMENT`
- `422`

## Meaning

A progress update was sent for an achievement that is not a progress type.

## What to do

Only send progress updates for achievements of type `progress`.
