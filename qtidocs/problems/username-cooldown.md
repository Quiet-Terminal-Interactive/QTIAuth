# USERNAME_COOLDOWN

## Code

- `https://qtiauth.qtidocs.dev/problems/username-cooldown`
- `USERNAME_COOLDOWN`
- `429`

## Meaning

The username was changed too recently; the cooldown period has not elapsed.

## What to do

Wait for the cooldown period to elapse before changing the username again.
