# KEY_INVALID

## Code

- `https://qtiauth.qtidocs.dev/problems/key-invalid`
- `KEY_INVALID`
- `400`

## Meaning

The redemption key does not exist or is otherwise not valid.

## What to do

Double-check the key value. If correct, contact support.
