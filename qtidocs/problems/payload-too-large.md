# PAYLOAD_TOO_LARGE

## Code

- `https://qtiauth.qtidocs.dev/problems/payload-too-large`
- `PAYLOAD_TOO_LARGE`
- `413`

## Meaning

The request body exceeds the route's body size limit.

## What to do

Reduce the payload size or split the request into multiple smaller requests.
