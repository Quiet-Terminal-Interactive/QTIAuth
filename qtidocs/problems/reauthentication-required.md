# REAUTHENTICATION_REQUIRED

## Code

- `https://qtiauth.qtidocs.dev/problems/reauthentication-required`
- `REAUTHENTICATION_REQUIRED`
- `403`

## Meaning

The session AAL is 0; the user must re-authenticate before proceeding.

## What to do

Prompt the user to sign in again to raise their authentication level.
