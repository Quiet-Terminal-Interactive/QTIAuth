# UNKNOWN_CLIENT

## Code

- `https://qtiauth.qtidocs.dev/problems/unknown-client`
- `UNKNOWN_CLIENT`
- `400`

## Meaning

The `client_id` in the request is not recognized.

## What to do

Verify the `client_id` value. Ensure the client has been registered on this platform.
