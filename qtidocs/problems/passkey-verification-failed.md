# PASSKEY_VERIFICATION_FAILED

## Code

- `https://qtiauth.qtidocs.dev/problems/passkey-verification-failed`
- `PASSKEY_VERIFICATION_FAILED`
- `401`

## Meaning

Passkey authentication cryptographic verification failed.

## What to do

Ask the user to retry. If repeated, the passkey may be corrupt, prompt them to register a new one.
