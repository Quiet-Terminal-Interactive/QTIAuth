# KEY_EXPIRED

## Code

- `https://qtiauth.qtidocs.dev/problems/key-expired`
- `KEY_EXPIRED`
- `400`

## Meaning

The redemption key has passed its expiry date.

## What to do

The key can no longer be redeemed. Contact support if this is unexpected.
