# APPEAL_ALREADY_OPEN

## Code

- `https://qtiauth.qtidocs.dev/problems/appeal-already-open`

## Meaning

There is already an open appeal for this moderation action.

## What to do

Direct the user to their existing appeal rather than opening a new one.
