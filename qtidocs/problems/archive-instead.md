# ARCHIVE_INSTEAD

## Code

- `https://qtiauth.qtidocs.dev/problems/archive-instead`
- `ARCHIVE_INSTEAD`
- `409`

## Meaning

The game is not in draft status; it must be archived or have its status changed instead of being deleted.

## What to do

Use the archive or status-change endpoint rather than delete.
