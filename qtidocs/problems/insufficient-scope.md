# INSUFFICIENT_SCOPE

## Code

- `https://qtiauth.qtidocs.dev/problems/insufficient-scope`
- `INSUFFICIENT_SCOPE`
- `403`

## Meaning

The OAuth access token does not include the required scope for this endpoint.

## What to do

Request a new token with the necessary scope.
