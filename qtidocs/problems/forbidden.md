# FORBIDDEN

## Code

- `https://qtiauth.qtidocs.dev/problems/forbidden`
- `FORBIDDEN`
- `403`

## Meaning

The request is understood but access is denied.

## What to do

Ensure the user has the required permissions. Do not retry without changing credentials or scope.
