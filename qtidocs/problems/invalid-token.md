# INVALID_TOKEN

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-token`
- `INVALID_TOKEN`
- `400`, `401`

## Meaning

The bearer token is missing, malformed, or fails signature verification.

## What to do

Obtain a fresh access token and retry the request.
