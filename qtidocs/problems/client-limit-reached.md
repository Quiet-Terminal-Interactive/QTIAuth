# CLIENT_LIMIT_REACHED

## Code

- `https://qtiauth.qtidocs.dev/problems/client-limit-reached`
- `CLIENT_LIMIT_REACHED`
- `409`

## Meaning

The user has reached the maximum number of OAuth applications.

## What to do

Delete an existing client before creating a new one.
