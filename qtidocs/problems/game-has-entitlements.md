# GAME_HAS_ENTITLEMENTS

## Code

- `https://qtiauth.qtidocs.dev/problems/game-has-entitlements`
- `GAME_HAS_ENTITLEMENTS`
- `409`

## Meaning

The game cannot be deleted because it has active entitlements.

## What to do

Remove all entitlements before deleting the game.
