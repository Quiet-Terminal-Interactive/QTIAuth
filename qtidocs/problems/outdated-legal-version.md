# OUTDATED_LEGAL_VERSION

## Code

- `https://qtiauth.qtidocs.dev/problems/outdated-legal-version`
- `OUTDATED_LEGAL_VERSION`
- `422`

## Meaning

The submitted legal version is outdated; a newer version has taken effect.

## What to do

Fetch the current legal document version and present it to the user for acceptance.
