# USERNAME_INVALID

## Code

- `https://qtiauth.qtidocs.dev/problems/username-invalid`
- `USERNAME_INVALID`
- `422`

## Meaning

The username format is invalid due to length or character restrictions.

## What to do

Inform the user of the username requirements and ask them to choose a valid one.
