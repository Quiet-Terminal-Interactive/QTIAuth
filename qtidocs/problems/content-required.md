# CONTENT_REQUIRED

## Code

- `https://qtiauth.qtidocs.dev/problems/content-required`
- `CONTENT_REQUIRED`
- `422`

## Meaning

A content ID is required for `remove_content` moderation actions.

## What to do

Include the content ID to be removed in the action request.
