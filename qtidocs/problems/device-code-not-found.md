# DEVICE_CODE_NOT_FOUND

## Code

- `https://qtiauth.qtidocs.dev/problems/device-code-not-found`
- `DEVICE_CODE_NOT_FOUND`
- `404`

## Meaning

The device authorization code is invalid or has expired.

## What to do

The user must restart the device authorization flow.
