# PASSKEY_NOT_FOUND

## Code

- `https://qtiauth.qtidocs.dev/problems/passkey-not-found`
- `PASSKEY_NOT_FOUND`
- `404`

## Meaning

The passkey was not found for this user.

## What to do

Verify the passkey ID and that it is registered to the current user.
