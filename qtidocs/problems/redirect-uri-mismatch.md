# REDIRECT_URI_MISMATCH

## Code

- `https://qtiauth.qtidocs.dev/problems/redirect-uri-mismatch`
- `REDIRECT_URI_MISMATCH`
- `400`

## Meaning

The `redirect_uri` supplied is not registered for this OAuth client.

## What to do

Use only redirect URIs that have been registered for the client.
