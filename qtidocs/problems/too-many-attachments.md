# TOO_MANY_ATTACHMENTS

## Code

- `https://qtiauth.qtidocs.dev/problems/too-many-attachments`
- `TOO_MANY_ATTACHMENTS`
- `409`

## Meaning

The maximum number of pending attachments per message has been reached.

## What to do

Commit or remove existing attachments before adding more.
