# TOO_YOUNG_TO_REQUEST_REMOVAL

## Code

- `https://qtiauth.qtidocs.dev/problems/too-young-to-request-removal`
- `TOO_YOUNG_TO_REQUEST_REMOVAL`
- `403`

## Meaning

The user is below the consent age and cannot request guardian removal.

## What to do

Inform the user they must reach the consent age before they can remove a guardian.
