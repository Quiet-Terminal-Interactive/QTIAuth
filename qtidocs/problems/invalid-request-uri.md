# INVALID_REQUEST_URI

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-request-uri`
- `INVALID_REQUEST_URI`
- `400`

## Meaning

The PAR `request_uri` is invalid, has expired, or does not belong to this client.

## What to do

Restart the Pushed Authorization Request flow from the beginning.
