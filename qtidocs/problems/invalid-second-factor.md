# INVALID_SECOND_FACTOR

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-second-factor`
- `INVALID_SECOND_FACTOR`
- `401`

## Meaning

The second-factor code (TOTP or passkey) is incorrect.

## What to do

Ask the user to try again with the current code. Check for clock skew if using TOTP.
