# TOKEN_VERIFICATION_UNAVAILABLE

## Code

- `https://qtiauth.qtidocs.dev/problems/token-verification-unavailable`
- `TOKEN_VERIFICATION_UNAVAILABLE`
- `503`

## Meaning

The token verification service is unavailable due to a JWKS fetch failure.

## What to do

Check JWKS endpoint availability and retry after a delay.
