# KEY_REVOKED

## Code

- `https://qtiauth.qtidocs.dev/problems/key-revoked`
- `KEY_REVOKED`
- `400`

## Meaning

The redemption key has been explicitly revoked.

## What to do

The key can no longer be redeemed. Contact support if this is unexpected.
