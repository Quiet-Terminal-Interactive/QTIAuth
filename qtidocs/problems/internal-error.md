# INTERNAL_ERROR

## Code

- `https://qtiauth.qtidocs.dev/problems/internal-error`
- `INTERNAL_ERROR`
- `500`

## Meaning

An unhandled internal server error occurred.

## What to do

Retry with exponential backoff. If the problem persists, check server logs and contact support.
