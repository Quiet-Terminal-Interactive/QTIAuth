# TICKET_CLOSED

## Code

- `https://qtiauth.qtidocs.dev/problems/ticket-closed`
- `TICKET_CLOSED`
- `409`

## Meaning

The support ticket is closed. It must be reopened before a reply can be added.

## What to do

Reopen the ticket before sending a reply.
