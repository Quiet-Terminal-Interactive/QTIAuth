# BOOTSTRAP_EMAIL_MISMATCH

## Code

- `https://qtiauth.qtidocs.dev/problems/bootstrap-email-mismatch`

- `422`

## Meaning

The email address does not match the bootstrap invitation token.

## What to do

Use the email address that matches the bootstrap invitation.
