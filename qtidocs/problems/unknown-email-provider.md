# UNKNOWN_EMAIL_PROVIDER

## Code

- `https://qtiauth.qtidocs.dev/problems/unknown-email-provider`

## Meaning

An unknown email provider is configured in the notifier service.

## What to do

Check the notifier service configuration and set a supported email provider.
