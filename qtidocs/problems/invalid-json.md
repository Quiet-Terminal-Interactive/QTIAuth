# INVALID_JSON

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-json`
- `INVALID_JSON`
- `400`

## Meaning

The request body is not valid JSON.

## What to do

Ensure the `Content-Type` is `application/json` and that the body is well-formed.
