# LEADERBOARD_NEEDS_GAME_AUTHORITY

## Code

- `https://qtiauth.qtidocs.dev/problems/leaderboard-needs-game-authority`
- `LEADERBOARD_NEEDS_GAME_AUTHORITY`
- `409`, `422`

## Meaning

The stat is used by a leaderboard that requires game authority, or the leaderboard configuration requires a stat with `authority: game`.

## What to do

Use a stat with `authority: game` for game-authority leaderboards.
