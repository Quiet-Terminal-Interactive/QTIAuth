# TOTP_ALREADY_ENABLED

## Code

- `https://qtiauth.qtidocs.dev/problems/totp-already-enabled`
- `TOTP_ALREADY_ENABLED`
- `409`

## Meaning

A TOTP authenticator is already confirmed and active on this account.

## What to do

Remove the existing TOTP authenticator before setting up a new one.
