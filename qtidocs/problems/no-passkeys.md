# NO_PASSKEYS

## Code

- `https://qtiauth.qtidocs.dev/problems/no-passkeys`
- `NO_PASSKEYS`
- `400`

## Meaning

The user has no passkeys registered, so passkey-only sign-in cannot proceed.

## What to do

Fall back to an alternative sign-in method, or prompt the user to register a passkey first.
