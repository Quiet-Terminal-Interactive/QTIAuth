# INVALID_CODE

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-code`
- `INVALID_CODE`
- `400`, `422`

## Meaning

The verification or TOTP code is wrong or has expired.

## What to do

Ask the user to re-enter the code, or request a new one if the window has passed.
