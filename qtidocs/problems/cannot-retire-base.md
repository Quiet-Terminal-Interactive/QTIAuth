# CANNOT_RETIRE_BASE

## Code

- `https://qtiauth.qtidocs.dev/problems/cannot-retire-base`
- `CANNOT_RETIRE_BASE`
- `409`

## Meaning

The base product of a game cannot be retired.

## What to do

Retire non-base products individually, or archive the game instead.
