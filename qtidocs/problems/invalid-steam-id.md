# INVALID_STEAM_ID

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-steam-id`
- `INVALID_STEAM_ID`
- `422`

## Meaning

The Steam ID format is invalid; it must be a 17-digit numeric string.

## What to do

Provide a valid 17-digit Steam ID.
