# ACTION_NOT_APPEALABLE

## Code

- `https://qtiauth.qtidocs.dev/problems/action-not-appealable`

## Meaning

The moderation action cannot be appealed because it is rejected or pending approval.

## What to do

Verify the action's status before opening an appeal.
