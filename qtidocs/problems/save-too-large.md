# SAVE_TOO_LARGE

## Code

- `https://qtiauth.qtidocs.dev/problems/save-too-large`

## Meaning

The cloud save data exceeds the configured slot size limit.

## What to do

Reduce the save data size to fit within the configured slot limit.
