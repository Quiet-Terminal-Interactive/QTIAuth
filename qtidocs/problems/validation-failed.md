# VALIDATION_FAILED

## Code

- `https://qtiauth.qtidocs.dev/problems/validation-failed`

## Meaning

The request failed schema validation. The `errors` field contains the specific issues.

## What to do

Read the `errors` array and correct each field before retrying.
