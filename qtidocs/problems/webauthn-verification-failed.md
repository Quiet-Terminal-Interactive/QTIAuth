# WEBAUTHN_VERIFICATION_FAILED

## Code

- `https://qtiauth.qtidocs.dev/problems/webauthn-verification-failed`
- `WEBAUTHN_VERIFICATION_FAILED`
- `400`

## Meaning

WebAuthn registration or authentication verification failed.

## What to do

Ask the user to retry. If the problem persists, the authenticator may be faulty or incompatible.
