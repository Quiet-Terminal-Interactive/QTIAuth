# TOKEN_REVOKED

## Code

- `https://qtiauth.qtidocs.dev/problems/token-revoked`
- `TOKEN_REVOKED`
- `401`

## Meaning

The bearer token has been explicitly revoked and can no longer be used.

## What to do

The user must sign in again to obtain a new token.
