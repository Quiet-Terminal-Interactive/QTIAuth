# BATCH_TOO_LARGE

## Code

- `https://qtiauth.qtidocs.dev/problems/batch-too-large`
- `BATCH_TOO_LARGE`
- `422`

## Meaning

The key batch count exceeds the configured maximum.

## What to do

Split the batch into smaller batches within the configured limit.
