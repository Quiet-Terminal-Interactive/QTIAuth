# INVALID_OR_EXPIRED_TOKEN

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-or-expired-token`
- `INVALID_OR_EXPIRED_TOKEN`
- `400`

## Meaning

An email verification token, magic link, or guardian invitation token is invalid or has expired.

## What to do

Request a new token and retry the flow.
