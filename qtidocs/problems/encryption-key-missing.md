# ENCRYPTION_KEY_MISSING

## Code

- `https://qtiauth.qtidocs.dev/problems/encryption-key-missing`
- `ENCRYPTION_KEY_MISSING`
- `503`

## Meaning

`APP_ENCRYPTION_KEY` is not configured; encrypted operations cannot proceed.

## What to do

Set the `APP_ENCRYPTION_KEY` environment variable and restart the service.
