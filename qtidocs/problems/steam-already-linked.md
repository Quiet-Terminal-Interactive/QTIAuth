# STEAM_ALREADY_LINKED

## Code

- `https://qtiauth.qtidocs.dev/problems/steam-already-linked`
- `STEAM_ALREADY_LINKED`
- `409`

## Meaning

A Steam account is already linked to this user.

## What to do

Unlink the existing Steam account before linking a new one.
