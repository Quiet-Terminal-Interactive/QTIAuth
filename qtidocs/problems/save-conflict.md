# SAVE_CONFLICT

## Code

- `https://qtiauth.qtidocs.dev/problems/save-conflict`
- `SAVE_CONFLICT`
- `409`

## Meaning

The client's base version for the cloud save is outdated; a newer version exists.

## What to do

Fetch the latest save version, merge changes, and retry with the updated base version.
