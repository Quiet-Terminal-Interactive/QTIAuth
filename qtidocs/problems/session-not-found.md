# SESSION_NOT_FOUND

## Code

- `https://qtiauth.qtidocs.dev/problems/session-not-found`
- `SESSION_NOT_FOUND`
- `404`

## Meaning

The user session was not found.

## What to do

The session has expired or been invalidated. The user must sign in again.
