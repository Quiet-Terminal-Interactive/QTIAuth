# NAME_USES_PRODUCT_NAME

## Code

- `https://qtiauth.qtidocs.dev/problems/name-uses-product-name`

## Meaning

The app name includes the product name without verification.

## What to do

Choose a different app name, or apply for permission to use the product name.
