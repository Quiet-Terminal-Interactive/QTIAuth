# ATTACH_AFTER_CREATE

## Code

- `https://qtiauth.qtidocs.dev/problems/attach-after-create`
- `ATTACH_AFTER_CREATE`
- `422`

## Meaning

Attachments cannot be included at ticket creation; they must be added in a reply.

## What to do

Create the ticket first, then add attachments in a follow-up reply.
