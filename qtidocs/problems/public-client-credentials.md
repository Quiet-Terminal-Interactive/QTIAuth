# PUBLIC_CLIENT_CREDENTIALS

## Code

- `https://qtiauth.qtidocs.dev/problems/public-client-credentials`
- `PUBLIC_CLIENT_CREDENTIALS`
- `422`

## Meaning

Public OAuth clients cannot use the `client_credentials` grant.

## What to do

Use a confidential client for the `client_credentials` grant.
