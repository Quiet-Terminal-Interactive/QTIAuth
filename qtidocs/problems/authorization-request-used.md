# AUTHORIZATION_REQUEST_USED

## Code

- `https://qtiauth.qtidocs.dev/problems/authorization-request-used`
- `AUTHORIZATION_REQUEST_USED`
- `409`

## Meaning

The OAuth authorization request has already been completed or denied.

## What to do

Restart the authorization flow to generate a new request.
