# STEAM_OPENID_INVALID

## Code

- `https://qtiauth.qtidocs.dev/problems/steam-openid-invalid`
- `STEAM_OPENID_INVALID`
- `400`

## Meaning

The Steam OpenID callback response is invalid or appears to have been tampered with.

## What to do

Restart the Steam sign-in flow. If the problem persists, investigate whether requests are being modified in transit.
