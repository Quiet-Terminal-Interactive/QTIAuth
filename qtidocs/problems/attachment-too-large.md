# ATTACHMENT_TOO_LARGE

## Code

- `https://qtiauth.qtidocs.dev/problems/attachment-too-large`
- `ATTACHMENT_TOO_LARGE`
- `413`

## Meaning

The attachment file exceeds the configured maximum size.

## What to do

Compress or resize the file before uploading, or split it into smaller parts.
