# UNAUTHENTICATED

## Code

- `https://qtiauth.qtidocs.dev/problems/unauthenticated`
- `UNAUTHENTICATED`
- `401`

## Meaning

No valid session or bearer token was found. Authentication is required.

## What to do

Redirect the user to sign in, or include a valid `Authorization` header.
