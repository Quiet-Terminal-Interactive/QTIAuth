# CHILD_ACCOUNTS_CANNOT_CREATE_CLIENTS

## Code

- `https://qtiauth.qtidocs.dev/problems/child-accounts-cannot-create-clients`
- `CHILD_ACCOUNTS_CANNOT_CREATE_CLIENTS`
- `403`

## Meaning

Child (under-13) accounts cannot create OAuth applications.

## What to do

Inform the user they must be an adult to register OAuth clients.
