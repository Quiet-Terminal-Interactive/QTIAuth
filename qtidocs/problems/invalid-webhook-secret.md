# INVALID_WEBHOOK_SECRET

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-webhook-secret`
- `INVALID_WEBHOOK_SECRET`
- `401`

## Meaning

The inbound webhook signing secret does not match.

## What to do

Verify the webhook secret and ensure it matches the configured value.
