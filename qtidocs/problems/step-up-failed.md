# STEP_UP_FAILED

## Code

- `https://qtiauth.qtidocs.dev/problems/step-up-failed`
- `STEP_UP_FAILED`
- `401`

## Meaning

The step-up authentication attempt failed, the code was wrong or verification did not succeed.

## What to do

Ask the user to retry with the correct code. After repeated failures, consider locking the flow.
