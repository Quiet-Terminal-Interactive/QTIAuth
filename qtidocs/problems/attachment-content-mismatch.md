# ATTACHMENT_CONTENT_MISMATCH

## Code

- `https://qtiauth.qtidocs.dev/problems/attachment-content-mismatch`
- `ATTACHMENT_CONTENT_MISMATCH`
- `415`

## Meaning

The file's actual contents do not match the declared `content_type`.

## What to do

Set the correct `content_type` for the file being uploaded.
