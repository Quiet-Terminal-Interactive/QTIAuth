# PLAYER_TOKEN_GAME_MISMATCH

## Code

- `https://qtiauth.qtidocs.dev/problems/player-token-game-mismatch`
- `PLAYER_TOKEN_GAME_MISMATCH`
- `401`

## Meaning

The player token was issued for a different game than the one being accessed.

## What to do

Use a player token issued for the correct game.
