# INVALID_DELEGATION

## Code

- `https://qtiauth.qtidocs.dev/problems/invalid-delegation`
- `INVALID_DELEGATION`
- `401`

## Meaning

The delegation token is missing or invalid.

## What to do

Obtain a valid delegation token and include it in the request.
