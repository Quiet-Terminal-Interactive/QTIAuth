# STAT_IN_USE

## Code

- `https://qtiauth.qtidocs.dev/problems/stat-in-use`
- `STAT_IN_USE`
- `409`

## Meaning

The stat is referenced by a leaderboard and cannot be deleted.

## What to do

Delete or update the leaderboard that references this stat first.
