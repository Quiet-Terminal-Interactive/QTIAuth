# PROVIDER_DENIED

## Code

- `https://qtiauth.qtidocs.dev/problems/provider-denied`
- `PROVIDER_DENIED`
- `400`

## Meaning

The OAuth or social provider denied the authorization, typically because the user cancelled.

## What to do

Inform the user and offer them the option to try again or use a different sign-in method.
