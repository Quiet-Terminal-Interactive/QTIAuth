# WRONG_CREDENTIAL_TYPE

## Code

- `https://qtiauth.qtidocs.dev/problems/wrong-credential-type`
- `WRONG_CREDENTIAL_TYPE`
- `401`, `403`

## Meaning

The credential type (session, OAuth, service, game-authoritative) is not accepted on this route.

## What to do

Use the correct credential type for this endpoint.
