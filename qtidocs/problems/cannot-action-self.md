# CANNOT_ACTION_SELF

## Code

- `https://qtiauth.qtidocs.dev/problems/cannot-action-self`
- `CANNOT_ACTION_SELF`
- `422`

## Meaning

A moderator cannot take a moderation action against themselves.

## What to do

Assign the action to a different moderator.
