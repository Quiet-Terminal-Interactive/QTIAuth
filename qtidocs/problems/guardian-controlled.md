# GUARDIAN_CONTROLLED

## Code

- `https://qtiauth.qtidocs.dev/problems/guardian-controlled`
- `GUARDIAN_CONTROLLED`
- `403`

## Meaning

This setting is managed by the user's guardian and cannot be changed by the child.

## What to do

Direct the user to ask their guardian to change the setting.
