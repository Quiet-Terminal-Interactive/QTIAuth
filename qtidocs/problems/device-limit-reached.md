# DEVICE_LIMIT_REACHED

## Code

- `https://qtiauth.qtidocs.dev/problems/device-limit-reached`
- `DEVICE_LIMIT_REACHED`
- `409`

## Meaning

The user has reached the maximum number of licensed devices.

## What to do

Remove an existing device before activating a new one.
